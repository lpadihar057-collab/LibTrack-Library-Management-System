# LibTrack-Library-Management-System
A Python-based Library Management System developed during my internship to manage books, members, issue/return records, and library operations.

LibTrack is a Python-based Library Management System developed during my internship at **GRAS**. The project is designed to simplify and manage common library operations such as adding books, managing members, issuing and returning books, and maintaining library records.

## 🚀 Features

* 📖 Add and manage books
* 👤 Manage library members
* 📤 Issue books
* 📥 Return books
* 🔍 Search books and records
* 📊 Manage library information
* 🗃️ Maintain book and member records
